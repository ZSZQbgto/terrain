# 地形模型编辑（terrain · modeldesigner）

在 **8 km DEM 三维地形**上做模型沙盘：导入多个 `.glb`、实时调整位置/旋转/缩放、复制摆放、
给模型或 glb 部件打标签（动态结构 / 静态标注），并把整个场景导出成工程 JSON。

地形渲染（分块 LOD、高程分层、日间薄雾、FXAA）复用自兄弟项目 `../terrain`，
**复制**了一份到 `src/terrain`、`src/viewer`，因此本项目可独立运行、不依赖父目录。

## 快速开始

```bash
cd modeldesigner
npm install
npm run dev        # http://127.0.0.1:5174
```

地形数据（`public/data/height.f16`、`terrain.json`）已随项目就绪；要换成别的区域，
把 16bit 灰度 DEM 放到 `resourses/heightmap64.png` 后执行 `npm run assets`。

## 模型从哪来

三种方式，最终都会汇入同一个**资源文件夹** `public/models/`：

| 方式 | 行为 |
| --- | --- |
| 把 `.glb` 直接放进 `public/models/` | 刷新页面即出现在左侧「资源库」（dev 下是实时目录扫描） |
| 网页「导入模型」或把文件拖进窗口 | dev server 会把它**写回 `public/models/`**（`POST /__models/upload`），同时放进场景 |
| 静态托管（`npm run build` 产物）导入 | 没有写盘能力，glb 暂存到浏览器 IndexedDB，界面上可「⇥ 移入文件夹」或「⭳ 下载」后自行放入 |

左侧「资源库」**始终显示资源文件夹里的内容**，其次是浏览器里暂存的资源（标注为「本地」）。

试试生成一个示例模型（底座 + 塔身 + 转臂，便于演示部件标签）：

```bash
npm run models:sample     # 生成 public/models/sample-tower.glb
```

## 地形贴图（可选）

地形贴图是**分块卫星瓦片 LOD**（与父项目 `terrain` 同一套实现）：8×8 = 64 块，
每块按「块到相机的最近距离」在三档之间切换：

| 档位 | 纹理 | 触发距离 | 显存/块 |
| --- | --- | --- | --- |
| 近景 | 2048² | < 1400 m | ≈21 MB |
| 中景 | 512² | 1400–3400 m | ≈1.3 MB |
| 远景 | 128² | > 3400 m | ≈85 KB |

**生成瓦片**：把卫星影像放到 `resourses/尚庄炉水库卫星影像64.png`，然后

```bash
npm run assets
```

会写出 `public/data/sat/{cx}_{cz}_{2048|512|128}.jpg`（192 张）并更新 `terrain.json`。
没有瓦片时地形自动回退到高程分层着色（启动时用一张远景瓦片探测目录是否存在），
功能不受影响。

## 全局贴图开关

工具栏的「贴图：开 / 关」同时控制两侧：

| 对象 | 开 | 关 |
| --- | --- | --- |
| 地形 | 卫星瓦片铺贴（需已生成瓦片） | 高程分层着色 |
| 模型 | 显示 glb 自带的贴图（`map`） | 材质摘掉 `map`，回退纯色 PBR |

开关状态存在 `localStorage`（`modeldesigner.settings.v1`），刷新后保持；
没有卫星瓦片时按钮仍可用（只影响模型贴图），tooltip 会注明当前地形没有贴图。

## 界面布局

顶栏只有四项：

| 顶栏 | 内容 |
| --- | --- |
| **项目管理 ▾** | 导出工程 / 导入工程 / 清空场景 |
| **模型编辑** | 左「场景资源」（资源库 + 导入 glb + 场景模型）｜右「模型编辑」（部件树 / 名称 / 变换 / 标签 / 贴地 / 删除） |
| **水体编辑** | 左「水体对象」（＋水面区域 / ＋流动水 + 水体列表）｜右「水体编辑」（撤回 / 重新编辑 / 保存 + 参数 + 水体标签） |
| **图形选项 ▾** | 贴图开关、碰撞开关、水面开关（含静止水与流动水）、标签显示、**薄雾强度**滑杆（0–3×） |
| **游览** | 隐藏全部面板进入无 UI 游览模式（相机带惯性缓动），`Esc` 或右下角按钮退出 |

两种模式**互斥**，且共用同一套两列栅格（左 340 px / 右 460 px）：顶栏与左右两栏的位置、
宽度在切换模式时完全不变，只有面板内容替换。上次停在哪个模式会记在
`localStorage`（`modeldesigner.settings.v1` 的 `uiMode`）。

### 游览模式

顶栏「游览」用于演示与截图：

- 隐藏工具栏、左右面板、底部提示与场景标签，只留右下角「退出游览 · Esc」
- 相机开启**惯性**：起步按指数缓动加速，松开按键后继续滑行一段再停；旋转阻尼也更柔
- 与编辑互斥：进入时会先取消正在进行的选点；`Esc` 或点右下角按钮退出，UI 与相机手感恢复原状

### 水体列表与编辑面板

水体模式是「左列表 + 右编辑面板」，与模型模式完全对称：

1. 点左上「＋水面区域」或「＋流动水」开始绘制
2. 点左侧列表里的对象，右侧会打开它的编辑面板：

- **撤回**：回退上一次水体修改（连续拖动数值滑块会合并成一步，不会一次退一点）
- **重新编辑**：重新点选边界 / 路径，双击完成后**替换**当前对象；名称、标签、流速/宽度都会保留
- **保存**：立即写入本地工程（平时改动也会自动保存）
- 其余：名称、水面高度（区域）/ 流速与宽度（流动水）、水体标签、删除

选中对象、编辑高度/流速、以及「重新编辑」过程中的每次选点，都是**实时渲染**的。

## 水面系统

不再有"覆盖全图的统一水面"，水面完全由**圈定的区域**和**流动水路径**组成。

### 同一套水贴图与光照

静止水面与流动水**共用同一个材质工厂**（`src/terrain/waterShaders.js` 的 `makeWaterMaterial`）：
同一份波纹法线贴图、同一套光照 —— **Schlick 菲涅尔**（正视看水下散射色、掠视看天空反射）+
天空渐变反射 + **双档日光镜面**（锐利太阳高光 + 较宽泛高光）+ 掠射角细碎水光，
以及和地形一致的日间薄雾。

**不糊也不闪的做法**：`src/terrain/waterTextures.js` 用 5 层 fbm 高度场差分生成一张
**可平铺的 256×256 法线贴图**，带完整 mipmap 链和 **各向异性过滤**（取 GPU 上限，实测 16×）；
shader 里再用两次不同尺度 / 不同速度的采样叠加，并按视线距离收敛法线强度 ——
近处是细碎波纹（不是大色块），斜视/远处由 mipmap 平滑，不会闪成噪点。

两者只差 uniform 与采样坐标：

| | 静止水面 | 流动水 |
| --- | --- | --- |
| `uFlow` | `0` | `1` |
| 采样坐标 | 世界坐标 `xz`（波纹随时间演化） | **UV**：`u` 横向、`v` 沿程距离 |
| 动画方向 | 缓慢起伏（无方向） | 相位只沿 `v` 推进 → **严格顺着水流线从起点滚向终点** |
| 横向收边 | 无（靠多边形裁切） | 两侧柔化收边 |

> 早前静止水面"看不见"的原因：它复用了地形里铺满全图的水面 shader，
> 却没传 `uHalfSize / uEdgeFadeStart / uEdgeFadeEnd`，边界淡出系数恒为 1，
> 最终 alpha 恒为 0 —— 整块水面完全透明。现在两者都走统一的 `makeWaterMaterial`。

### 圈定水面区域

1. 点左侧「＋水面区域」进入绘制，**右侧面板立刻出现草稿**（点数 / 实时平均水面 / 撤回上一点 / 完成 / 取消）
2. 在地形上依次点选边界：每个选点都有**黄色小球 + 序号**（1、2、3…），并自动连线
3. 每加一个点都会把各点地表高程求平均，预览里立刻出现**真实水面** ——
   用的是与最终水面同一套 shader（波纹 + 雾），高度就是这个平均值
4. 至少 3 点后「完成」按钮可用，点它结束；`Esc` 取消

> 选点走 `cameraControls.pick()`（射线步进 + CPU 高度采样）取交点。地形几何本身是**平面**的
> （高度在 shader 里位移），所以不能靠 raycast 打网格 —— 那样点会落在 y=0 平面上，位置全错。

完成后区域被选中，右侧可改：**名称 / 标签**、**水面高度（米）**（默认就是平均高度）、删除。

### 流动水路径

1. 点「＋流动水」→ 起点 → 若干途经点 → 终点（≥2 点），选点同样带序号标记
2. 一满 2 点就出现**实时水带预览**（与最终流动水同一套流动材质）
3. 点「完成」结束；之后可改名称、**流速（倍率）**、**宽度（米）**

**水带贴到表面**：每个采样点都会投射到场景表面 —— 先打模型几何（glb 是真实几何，
能拿到面法线），没命中再用地形 CPU 高度采样兜底。横向方向用「曲线切线 × 表面法线」，
所以水带能沿坡面、坝顶、渠壁铺开，水贴图正好**覆盖在物体贴图之上**，不会浮空。

**每个关键点独立宽度 / 方向**：编辑面板里的「关键点」区给每个点两个数字框：

| 字段 | 含义 |
| --- | --- |
| 宽 m | 该点的水带宽度，沿曲线在相邻关键点之间线性插值（留空/未改则跟随全局宽度） |
| 方向 ° | 该点的**横向朝向**，绕表面法线旋转；`0°` = 自动方向（切线 × 法线） |

实测把 P1/P2/P4 改成 70 / 60 / 4 后，水带横截面为 `70 → 43 → 4 m`，沿程平滑过渡。

水带纹理沿路径方向滚动，流速越大动画越快；两侧柔化收边，避免硬直边。

### 拖动节点

选中水体后，场景里会出现一排**青色编号节点**（就是它的关键点），直接用左键拖：

| 类型 | 可改的坐标 | 拖动所在的平面 |
| --- | --- | --- |
| 静止水面区域 | **水平位置**（x / z） | 该水面所在的水平面 —— **水面高度 `level` 保持不变** |
| 流动水 | **空间位置**（x / y / z） | 过该节点、朝向相机的平面 —— 可以把水流拖到坝顶、渠壁或任意高度 |

- 拖动时相机自动锁定，松开鼠标提交一次变更（进撤回栈 + 自动保存），拖动过程中水面/水带实时重建
- 节点上的编号与面板「关键点」里的 P1、P2… 一一对应；宽度与方向仍在面板里调

### 撤回与重新编辑

- **撤回上一点**：只在绘制过程中出现，撤掉**刚刚选的那个点**（序号、连线、水面同步回退）
- **重新编辑**：对已有对象重新点选边界 / 路径，完成后**替换**原对象（名称、流速/宽度保留）

对象编辑面板里没有「撤回」——撤回只属于"撤销刚选的点"这件事。

### 水面总开关

「图形选项 ▾ → 水面：开 / 关」隐藏/显示所有水面区域与流动水（状态存 `localStorage`）。

### 薄雾强度

「图形选项 ▾ → 薄雾强度」滑杆（0–3×，默认 1.0×）一次调节三方：

| 对象 | 用的是什么 |
| --- | --- |
| 地形 | 自定义日间雾 `env.uFogDensity`（按高度衰减的 haze） |
| 水面（静止 + 流动） | 直接引用同一份 `env.uFogDensity`，拖动即为所见 |
| 模型 | three 的 `scene.fog`（FogExp2），密度同步调整 |

状态存在 `localStorage`，刷新后保持。

### 水体名称即标签

水体的「名称 / 标签」是同一个字段：填什么，左侧列表就叫什么；它**不在场景里显示**，
也不会生成 CSS2D 胶囊，与物体/部件的标签数据完全分开。

## 操作

### 视角

| 操作 | 功能 |
| --- | --- |
| 左键拖拽 / 右键拖拽 | 旋转 / 平移 |
| 滚轮 | 缩放（指向光标） |
| `W` `A` `S` `D` · `Q` `E` | 相机水平移动 · 升降 |
| 按住 `Shift` + 移动键 | 加速 3.2× |
| 按住 `Ctrl`（macOS 也认 `⌘`）+ 移动键 | 缓动 0.25×，用于微调构图 |
| 双击地表 | 聚焦到该点 |

### 相机碰撞

工具栏「碰撞：开 / 关」控制相机是否被地形挡住：

- **开**（默认）：不会钻进地形（按最小离地高度贴地），也不会飞出地形方形边界
- **关**：自由穿行 —— 可以钻到地形以下、飞出土地方形范围，方便检查地下/边界效果

状态存在 `localStorage`（`modeldesigner.settings.v1` 的 `cameraCollision`），刷新后保持。

### 编辑

检查器自上而下是：**部件 → 名称 → 变换 → 标签 → 模型**。
所有编辑都跟随「当前选择」——而选择只有两种来源：

| 操作 | 功能 |
| --- | --- |
| 在**部件栏**点「整个模型」/ 某个部件 | 决定下面「名称 / 变换 / 标签」作用于谁 |
| 左键点场景里的物体 | 只选中**整个模型**（不会选中部件） |
| `1` / `2` / `3` | 切换 gizmo：移动 / 旋转 / 缩放 |
| 拖 gizmo | 实时变换当前选择，检查器的 P/R/S 数值同步刷新（拖动期间自动禁用相机，避免带转视角） |
| 检查器数值框 | 精确输入位置（米）/ 旋转（度）/ 缩放（倍率）；每轴带 X/Y/Z 标记，颜色与 gizmo 轴一致（X 红 / Y 绿 / Z 蓝） |
| 名称输入框 | 改当前选择的名称：整体改模型名，部件改该节点名（写进工程） |
| 「贴地」 | 把模型包围盒最低点落回地表（作用于整个模型） |
| 「删除模型」 / `Delete` | 删除整个模型 |
| `Ctrl+D` / 列表里的 ⧉ | 深拷贝一份（含标签与部件变换），偏移 60 m 放置 |
| `Esc` | 取消选择 |

> 没有「编辑模型 / 编辑部件」这类开关：点部件栏里的谁，就编辑谁。

### 标签

标签挂在**当前选择**上，列表也只显示当前范围的标签：

1. 在部件栏点「整个模型」或某个部件
2. 在名称框里填**标签名称**（留空则用模型名 / 部件名），点「+ 添加」
3. 新标签**默认为「静态标注」**（琥珀色胶囊），需要时在标签卡上点
   「动态结构」（青色）切换类型，之后可随时改
4. 名字和类型都可以随时改；类型只是给这个标签定性，不附带别的作用

> 也就是说：**创建时只管名字，默认静态标注，类型随时可改**；标签只属于它挂的那个对象。

## 工程与持久化

- **自动保存**：任何编辑 400 ms 后写入 `localStorage`（工程结构与 glb 分离）
- **刷新恢复**：glb 从 `public/models/` 或 IndexedDB 重新读取，变换与标签全部还原
- **导出工程**：`导出工程` 按钮 →
  - 确定 = **内嵌 glb**（单文件，可跨机器，体积大）
  - 取消 = **只导出引用**（依赖 `public/models/` 里的文件）
- **导入工程**：会替换当前场景；内嵌模式会自动把 glb 写回资源文件夹
- **清空场景**：只清实例与本地工程，不动资源文件夹

导出 JSON 的逐字段说明（坐标约定、单位、索引路径、标签结构）见
**[docs/EXPORT-FORMAT.md](docs/EXPORT-FORMAT.md)**。

## 功能清单

已实现：

- 多 glb 导入（文件选择 / 拖拽 / 直接放资源文件夹），资源列表实时反映目录
- 模型实例：选择、显示/隐藏、复制、删除、贴地、重命名
- 地形贴图：分块卫星瓦片 LOD（三档按距离切换），无瓦片时自动回退高程分层
- 全局贴图开关：一键切换地形卫星影像与模型自带贴图
- 相机：碰撞开关（可关掉后自由穿行）、`Shift` 加速 / `Ctrl` 缓动
- 水面：圈定区域（选点实时平均高度，可再编辑）、流动水路径（平滑曲线 + 流速）、总开关、水体标签
- 场景默认：水面高程 **69 m**（`main.js` 的 `DEFAULT_WATER_LEVEL`，新建水面区域的默认高度）
- 实时变换：TransformControls（世界/局部）+ 数值输入双向同步
- 部件级编辑：部件栏选择 + 部件局部变换与改名（都会写进工程）
- 标签：模型级 / 部件级；先只填名称创建（未分类＝灰色胶囊），再在卡片上选「动态结构 / 静态标注」，场景内 CSS2D 跟随显示并按类型配色
- 持久化：localStorage 工程 + IndexedDB glb，刷新恢复
- 工程导入导出（引用模式 / 内嵌模式）
- 与地形一致的雾、光照、色调；帧率自适应降分辨率

暂未包含：

- 动态结构的动画/驱动（只有参数模型）
- 把编辑结果烘回 glb 导出
- 撤销/重做、多选、对齐吸附
- 服务器端存储（纯前端，数据在本机）

## 已知限制

- `.gltf`（文本）若引用外部 `.bin`/贴图，单独导入会缺资源 —— 请优先用单文件 `.glb`
- 静态托管下导入的模型只存在浏览器里（换浏览器/清缓存会丢），请用「移入文件夹」或下载后放进 `public/models/`
- 资源文件夹的写入依赖 dev server 的 `/__models/*` 接口；`npm run preview` 与生产托管没有这些接口
- 单模型上限 256 MB；文件名不允许路径分隔符与 `: * ? " < > |`（会被拒绝）
- 水面区域是**水平面**（高度取选点平均），地形起伏处可能穿模；要贴地形请用流动水路径
- 水面/流动水的选点暂不支持拖动改点：要调整形状就删掉重画（高度、流速、宽度可以随时改）
